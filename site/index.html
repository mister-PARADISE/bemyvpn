Как это работает

1

Открываете приложение и видите список людей, которые согласились пускать других через свой интернет. У каждого — страна и сколько уже гостей.

2

Выбираете любого, жмёте «Старт» — и сайты видят его страну, а не вашу. Если кто-то включил хост лично для вас, он даст короткий код: в общем списке такого не будет.

3

Дальше вы общаетесь напрямую. Наш сервер только помогает вам найти друг друга и в разговор не лезет — трафик через него не идёт.

4

Можно и наоборот: пустить кого-то через себя. Тогда VPN для него — вы.

Пустить других через себя

Поставить на серверОдна команда — и вы работаете чьим-то VPN круглосуточно

Скопируйте в терминал сервера

curl -fsSL https://github.com/mister-PARADISE/bemyvpn/releases/latest/download/bemyvpn-linux-$(uname -m | sed s/aarch64/arm64/)-terminal -o bemyvpn && chmod +x bemyvpn && sudo ./bemyvpn install && sudo bemyvpn

Команда сама подставит нужную сборку, скачает её и поставит в систему — дальше достаточно набрать bemyvpn из любой папки. Откроется меню: имя, сколько пускать гостей, пароль. Там же включается работа круглосуточно, чтобы всё продолжалось после выхода из SSH и перезагрузки.
