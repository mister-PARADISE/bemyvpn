# ============================================================
#  BeMyVPN — список STUN-серверов
# ============================================================
#  STUN помогает двум устройствам узнать свой внешний адрес и найти
#  друг друга сквозь NAT. Трафик через себя STUN НЕ пропускает и ничего
#  про тебя не хранит — только отражает адрес. Бесплатно, без регистрации.
#
#  Формат: один сервер на строку, host:port. Строки с # — комментарии.
#  Чем больше серверов из РАЗНЫХ сетей/стран — тем выше шанс пробить NAT
#  где угодно. Приложение пробует их по очереди, хватает одного ответа.
# ============================================================
