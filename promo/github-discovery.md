# GitHub как канал: что поменять руками

Это то, что я не могу применить сам — у меня нет доступа к настройкам репозитория
(MCP-инструмента на правку метаданных нет, прямой API закрыт прокси). Всё ниже —
копипаста, минут на десять. По отдаче на минуту это лучшее, что есть в списке.

Главный вывод: **0 звёзд за 17 дней — это не отказ рынка, это отсутствие показов.**
Разница принципиальная. Не надо чинить продукт, надо чинить видимость.

Побочное следствие, неприятное, но лучше знать заранее: почти все awesome-списки
и каталоги требуют возраста и минимальной популярности. С нулём звёзд и возрастом
в две недели туда сейчас **не примут**, и подавать заявку рано — отказ запоминается
мейнтейнерам. Сначала первая волна и первые живые хосты, каталоги потом.

## 1. Description (самое важное поле)

Сейчас: `Интернет через друга, а не через сервер. P2P VPN без регистрации и аренды серверов.`

Хорошая фраза, но она отрезает весь англоязычный поиск. Поиск GitHub ищет по
description, а англоязычных запросов «p2p vpn» на порядки больше русских.

**Ставить вот это** (350 знаков — влезает, ключевые слова внутри):

```
P2P VPN where the exit node is a volunteer's computer, not a company's server. No signup, no payment, and hosting needs no root. Rust, 5 platforms. // Интернет через друга, а не через сервер — без регистрации и аренды серверов.
```

Английский первым — по нему идёт поиск; русский после `//` — его читают те, кто
уже пришёл по ссылке. Так поле работает на обе аудитории.

## 2. Homepage

Сейчас пусто. Поставить `https://bemyvpn.net` (или адрес зеркала на Pages, если
домен недоступен). Поле показывается крупно справа вверху и кликается чаще, чем
любая ссылка внутри README.

## 3. Topics

Сейчас: `censorship-circumvention` `nat-traversal` `p2p` `rust` `vpn`

Пять хороших, но лимит — 20, и каждый тег это отдельная страница-каталог, куда
люди заходят просматривать проекты. Незаполненные теги — это упущенные показы,
причём бесплатные.

**Добавить** (проверьте на существование — теги без подписчиков бесполезны):

```
privacy  self-hosted  wireguard  noise-protocol  hole-punching
decentralized  anti-censorship  vpn-client  android  cross-platform
free-speech  networking  tun  peer-to-peer  no-root
```

Приоритет, если хочется коротко: `privacy`, `self-hosted`, `wireguard`,
`decentralized`, `noise-protocol`. Первые два — самые населённые каталоги, где
водятся ровно владельцы VPS.

## 4. Discussions — включить

`Settings → Features → Discussions`.

Зачем: хостам нужно место, где они видят друг друга. Сейчас человек запускает
хост и остаётся в одиночестве — он не знает, есть ли вообще кто-то ещё. Issues для
этого не годятся, там баги.

Завести сразу две темы:
- **«Кто раздаёт»** — люди отмечаются, что подняли хост, страна, аптайм. Это
  превращает невидимую сеть в видимое сообщество и заметно влияет на то, будет ли
  хост жить дальше первой недели.
- **«Нужна помощь»** — куда приходят те, кому не хватает хоста в конкретной стране.

## 5. Pages — включить

`Settings → Pages → Build and deployment → Source: GitHub Actions`

Без этого прогон `.github/workflows/pages.yml` (уже в ветке) упадёт. После
включения появляется второй, независимый адрес страницы скачивания:
`https://mister-paradise.github.io/bemyvpn/`

Зачем — подробно в шапке самого workflow: сейчас страницу отдаёт координатор, и
блокировка его домена лишает человека не только каталога, но и возможности скачать
приложение вообще. То есть даже сменить координатор в настройках он уже не сможет:
приложения у него нет.

## 6. Wiki — выключить

Включена и пуста. Пустой пункт меню выглядит как заброшенный проект. Вся
документация и так в `docs/`.

## 7. Release — проверить оформление

Релизы — недооценённая витрина: GitHub показывает их в ленте подписчиков и
индексирует поиском. Стоит убедиться, что в теле последнего релиза есть одна
строка по-английски и команда установки хоста — человек, попавший на страницу
релиза из поиска, часто дальше не идёт.

## Чего это НЕ даст

Честно, чтобы не было завышенных ожиданий: метаданные не приводят людей сами.
Они делают так, что пришедший **находит** проект и **понимает**, что это, за пять
секунд. Это множитель к трафику, а не источник трафика.

Источник трафика — статьи и сообщества. Множитель без трафика даёт ноль, поэтому
метаданные надо привести в порядок **до** первой публикации, а не после.
