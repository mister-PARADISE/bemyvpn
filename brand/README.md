# Бренд BeMyVPN — «Звено»

Логотип: два сцепленных кольца — два человека, прямое P2P-соединение без
посредника. Синее кольцо — гость, мятное — хост; сплетены как звено цепи
(снизу синее поверх, сверху зелёное).

## Файлы
- `logo.svg` — глиф на прозрачном фоне (мастер-вектор, канон геометрии)
- `icon.svg` — глиф на фирменной тёмной плитке (превью иконки)
- `icon-1024.png` / `icon-512.png` — растр с фоном (iOS AppIcon, сторы, сайты)
- `glyph-512.png` — глиф без фона (наложение на любую поверхность)

Перегенерация растра: скрипт рисует кольца программно (Pillow, суперсэмплинг 4×) —
геометрия и цвета продублированы в нём и в `logo.svg`; меняешь — меняй оба.

## Канон
- Геометрия (viewBox 100): центры (37,50) и (63,50), r=19, толщина 11.
- Цвета: синий #6EA2FF→#3D6FE0 (вертикально), мятный #3EE6A8→#14B981.
- Фон плитки: #101726→#0B0E14 (палитра приложения, Theme.bg).
- Без текста. Не вращать, не менять пропорции, не перекрашивать половинки.

## Где используется
- iOS: `apps/ios/BeMyVPN/Assets.xcassets/AppIcon.appiconset` (1024 PNG)
- Android: `apps/android/app/src/main/res/drawable/ic_launcher_{foreground,background,monochrome}.xml`
  (adaptive, вектор — та же геометрия в viewport 108, глиф ×0.8 в безопасной зоне)
