# Периметр

Панель для аудита сайтов по согласию владельца, в стиле терминала. В ней хранятся цели (сайты): у каждой есть границы проверки и отметка о согласии владельца. Инструменты подключаются как модули. Клиенты и счета появятся позже отдельным расширением.

## Запуск

| Система | Команда |
|---|---|
| macOS, Linux | `./start.sh` |
| Windows | `start.bat` |

При первом запуске скрипт сам создаст окружение и поставит зависимости, затем панель откроется в браузере и попросит придумать имя и пароль администратора.

- Адрес: `http://127.0.0.1:8710`, слушает только этот компьютер.
- Данные (база, ключ сессий, свои плагины) лежат в папке `data/` рядом.
- Другой порт: `./start.sh --port 9000`. Без браузера: `--no-browser`.
- Если забыли пароль: `.venv/bin/python -m perimeter reset-password admin`.

Нужен Python 3.11 или новее.

## Что уже есть

| Раздел | Что делает |
|---|---|
| Обзор | Последние цели, модули, состояние системы, журнал в виде `tail -f` |
| Цели | Домен (кириллица и `www` приводятся к одному виду), отметка о согласии и границы: дополнительные домены, IP, подсети, исключения. Есть проверка «входит ли адрес» |
| Модули | Каталог инструментов: пассивные и активные, какие данные принимают и выдают, кто кого может продолжить |
| Журнал | Каждое действие: кто, что и когда. Записи остаются после удаления объекта |
| Настройки | Формы строятся из описаний полей: название, часовой пояс, цвет терминала, плотность, пароль |

Быстрые клавиши: `/` или `Ctrl K` — поиск по всему, `Ctrl B` — свернуть панель.

Оформление: почти чёрный фон, зелёный люминофор (есть янтарный и бирюзовый), шрифт JetBrains Mono лежит в самой панели и из интернета не грузится. На телефоне таблицы складываются в карточки, ни одна страница не вылезает за ширину экрана.

## Согласие владельца — одна галочка

Клиенту ничего делать не нужно: никаких записей в DNS, файлов на сайте и кодов. Отметку «владелец согласен» ставите вы сами, а откуда согласие — по желанию одной строкой.

Каждый модуль в паспорте указывает свой вид:

- **пассивный** — берёт данные из открытых источников (WHOIS, DNS, логи сертификатов) и к сайту не обращается. Работает для любой цели, например чтобы показать будущему клиенту, что про его сайт видно снаружи;
- **активный** — шлёт запросы сайту (порты, заголовки, файлы). Запустится только у цели с отметкой о согласии и только в её границах.

Проверку делает ядро, а не автор модуля, поэтому новый модуль её не обойдёт. Галочка нужна не клиенту, а вам: активная проверка чужого сайта без согласия может трактоваться как неправомерный доступ.

## Как устроено

Всё, кроме ядра, — расширения. Встроенные лежат в `perimeter/extensions/`, свои — в `data/plugins/<имя>/__init__.py`. И те и другие устроены одинаково: функция `setup(ctx)` регистрирует нужное.

```python
def setup(ctx):
    ctx.pages.add(Page("reports", "Отчёты", "/reports", icon="file"))   # пункт меню
    ctx.add_router(router)                                               # страницы FastAPI
    ctx.widgets.add(Widget("risk", "Риски", "reports/_widget.html"))    # блок на «Обзоре»
    ctx.add_slot("target.main", Slot("scans", "reports/_scans.html"))    # блок в чужой странице
    ctx.settings.section(SettingsSection(id="shodan", title="Shodan",    # раздел настроек
        group="Модули", fields=(f.secret("api_key", "Ключ API"),)))
    ctx.modules.add(Whois)                                               # инструмент
    ctx.events.on("target.authorized", notify)                          # реакция на событие
    ctx.hook("target.before_delete", check)                              # право вето
    ctx.search(find_reports)                                             # результаты в поиске
```

- Шаблоны из папки `templates/` расширения подключаются сами.
- Если `setup` упал, всё, что расширение успело зарегистрировать, откатывается. Ошибка видна в «Модули → Расширения».
- Поля (`core/fields.py`) общие для настроек, форм и параметров модулей: одно описание даёт форму, проверку ввода и значение по умолчанию.

```
perimeter/
  core/        реестры, события, поля, настройки, границы, контракт модулей, загрузчик расширений
  web/         сборка приложения, вход, CSRF, шаблоны и дизайн-система (static/app.css, app.js, fonts/)
  extensions/  обзор, цели, каталог модулей, журнал, настройки
tests/         ядро, вход и защита, цели и согласие, миграции, настройки, поиск, расширения
```

## Безопасность самой панели

- Пароль хранится как scrypt-хэш, после 5 неудачных входов вход блокируется на 5 минут.
- Смена пароля завершает все остальные входы.
- Все формы защищены CSRF-токеном.
- Заголовки CSP, `X-Frame-Options`, `no-store` для страниц; внешние скрипты и шрифты не грузятся.

5. **Клиенты и счета** — отдельным расширением, когда всё остальное будет работать как надо.
