## Найдено запуском (и только запуском)

- **VO: Better Dogs** — миксин на волка собран под другую сигнатуру метода — Fabric падает на трансформации класса. А с его библиотекой Dasik Library мод требует Java 25, тогда как 1.21.11 работает на Java 21.
- **Better Smoke** — миксин AbstractParticleAccessor ищет поле частицы field_3861, которого в 1.21.11 нет — клиент падает на старте.
- **Even Better Moon and Sun** — миксин не находит цель в классах 1.21.11 — клиент падает на старте.
- **Hear the Wind** — миксин не сходится с 1.21.11 — клиент падает на старте.
- **Mining & Placing Animations** — миксин не сходится с 1.21.11 — клиент падает на старте.

## Осталось в логе, не мешает игре

- **Do a Barrel Roll и Controlify не договариваются** — При старте клиента интеграция Do a Barrel Roll с Controlify падает с AbstractMethodError: мод собран под другую версию API геймпадов. На игру это не влияет — ошибка ловится и записывается в лог, полёт на клавиатуре работает. Пострадает только управление полётом с геймпада.
- **Пятнадцать моделей висячих табличек Wilder Wild** — В логе пятнадцать строк «Error creating model for hanging_sign/wilderwild:...» — у мода не сходятся модели висячих табличек для его пород дерева. Таблички из ванильного дерева в порядке, всё остальное в моде работает.
- **AmbientSounds и CreativeCore жалуются на формат пака** — Оба объявляют формат ресурспака 50, а 1.21.11 понимает до 17-го. Игра пишет предупреждение и грузит их дальше — звук работает, проверено на запущенном клиенте.
- **Player Corpses ищет мод Trinkets** — Дважды за старт сервера пишет «Failed to load function player_corpses:items_add/items_add_trinkets_continued» — это необязательная интеграция с модом, которого в сборке нет. На работу трупов не влияет.
