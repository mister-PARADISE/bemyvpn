# Слои погружения — каталог модов на реализм для Minecraft 1.21.11 (Fabric)

`realism-mods.html` — самодостаточная страница, открывается двойным кликом, без сервера и интернета
(картинки встроены; из сети подтягиваются только шрифты, без них страница читается ровно так же).

`realism-mods.json` — те же данные без картинок: 152 позиции, 20 правил о конфликтах,
27 модов, которых под 1.21.11 не существует.

## Что внутри страницы

- **152 позиции** — моды, ресурспаки, шейдеры и датапаки, каждый с проверенной поддержкой 1.21.11 + Fabric.
- Приоритет у каждой позиции: обязательно / сильно советую / по вкусу / на любителя.
- Для каждой — что делает, зачем именно этой сборке, конфликты и зависимости, скриншот, ссылки.
- Фильтры по слою и приоритету, поиск, чек-лист «в сборку» с выгрузкой списка.
- Раздел взаимоисключений и таблица модов, которые 1.21.11 пропустили.

## Как собиралось

Целевая сборка: Minecraft Java 1.21.11, Fabric, поверх модпака Fabulously Optimized 12.2.2.
Состав модпака взят из его `modrinth.index.json`, чтобы каталог не дублировал уже установленное.

1. Перебор Modrinth по API — 10 455 проектов, реально совместимых с 1.21.11; 749 разобраны подробно.
2. Скрининг и поиск пробелов — 17 агентов.
3. Кураторская чистка по категориям с проверкой фактов — 12 агентов.
4. Состязательная проверка — 5 агентов; часть модов распаковывалась из jar, чтобы убедиться,
   что заявленные функции и настройки существуют. 100 карточек подтверждены без изменений,
   в 45 внесены правки, 12 позиций добавлены по итогам разбора пробелов.

Данные о версиях, зависимостях и загрузках — на 19 августа 2026 года.
